# 交汇点切磨：用真实目标保持刻面连接

适用于原创、改型与补全设计。先确定外形、台宽、腰厚和主面布局，再让需要会合的刻面穿过已有交点。Meet 保存施工意图；它不是判断设计好坏的唯一方法，明确数值求解的切面也可以正确。

## 先写自由量与目标

| 部位 | 可先确定的量 | 需要核对的连接 |
| --- | --- | --- |
| 外形与腰 | 尺寸、分度、允许的预成型区域 | 腰角是否落在预期主面尖端方向 |
| 亭部 | 第一层角度、深度、底尖或龙骨位置 | 后续主面与下腰面如何会合 |
| 冠部 | 冠高、腰厚、台宽 | 主面、星面、上腰面与台面连接 |
| 局部细节 | 棱上比例点、阶梯宽度、尖端保护 | 短棱、小面是否为设计本意 |

单点 Meet 保持角度求深度，双点 Meet 固定分度求角度与深度。先切出目标，再引用真实施工前缀。对称不足以产生底尖时，可用临时中心点；临时层即使最终被覆盖也保留施工记录。

默认立方体项目的固定台面有保护规则，尽量在依赖它的 Meet 之前定好高度。mesh 项目从零 CUT 开始，不套用“台面必须第一层”的限制。修改早期参数后检查 Meet 来源，不自动假设后续切面会跟随重算。

## MCP 与网页入口

- `design_topology`（可带 `beforePatternId`）读取顶点和棱；按真实来源面组合选目标。
- 单点：`meet: { a }`；棱上点同时给 `ratioA`，从该棱 `endpoints[0]` 算起。
- 双点：`meet: { a, b, ratioA?, ratioB? }`；检查求解角度、主成员及完整对称轨道。
- `design_jump` 查草稿可以到达的真实顶点；构造后按 `design_plan → design_view / design_inspect → design_commit → project_save` 完成。
- 网页“更多工具 → 交点检查”与 `design_inspect.meetAudit` 调用同一正式检测入口；网页检查完整已保存设计，包括临时隐藏层，草稿不参与。MCP 指定 `planId` 时检查该计划文档，不能把计划结果当作已保存。

## 如何读整颗诊断

检测由 application/domain 实现，Skill 不维护另一套算法。兼容离线入口：

```sh
node .agents/skills/facet-parametric-design/scripts/meet-audit.mjs design.json --json
```

正常完成返回 0，即使有候选；不支持返回 2；输入或执行失败返回非零。旧 `--brilliant` 参数仍可传入，但不会启动强制清零门槛。

- **范围：** 纯平切成品（包括 mesh 底胚）。启用凹切时返回 `unsupported / active-concave-cuts`，不以凹切前实体代替成品；禁用的凹切不影响检查。没有有效 CUT 时也不报告“全绿”。
- **尺度：** W 为成品 X 向宽度。0.1% W 是分析聚类容差，**不是几何内核的数值精度**，也不是实际加工公差。
- **相邻交点候选 `nearMisses`：** 聚类后相距小于 1% W 的真实转角。正常腰厚的上下对应点排除；标签改名不影响分类。临近不等于本应重合。
- **短棱候选 `splitMeets`：** 内部两个三面点间短于 12% W 的棱，排除同方位上下阶梯。刻面族与设计意图可能使短棱合理；不能凭长度判为错误。
- **其他测量：** 腰线高差、小于同类中位面积 15% 的小面、有效台面转角、原胚壁面片及其冠亭交线高差。无分面腰时对应高差为 null，网页显示“无分面腰”，不报告为零高差。
- **逻辑面：** 多块 mesh 面片仍按其 CUT 身份统计。被覆盖工序不计为有效面，原胚面片不冒充 CUT。

先在真实视图中定位候选，再对照设计意图。需要修复的是不符合目标的会合关系，不是所有候选。指定连接仍用 [拓扑检查](topology.md)；线稿、轮廓、心口壁厚和光学表现另行评价。

## 可复现的对照练习

起点为内置 **Eight Main Highlight**（`94504-pc-01-338-eight-main-highlight`），完整设计在仓库 `public/presets/documents/94504-pc-01-338-eight-main-highlight.json`，新建项目 → 从预设琢型开始可搜索。

1. 记录原设计的交点检查和顶视图；原设计短棱候选为 0。
2. 另存副本，将台面切深增加 0.01（本例约 0.5% W），其他参数保持不变。
3. 再检查：会出现 8 个短棱候选，而相邻交点候选仍为 0。保持相同顶视、缩放和显示方式，观察台面角如何分开。
4. 撤销台面修改，核对恢复。判断问题：这些短棱是否符合你想要的台面布局？工具不能替你决定。

工程回归覆盖上述对照、主面偏移、薄腰、改名、被覆盖台面，以及凹切的范围反馈。设计师是否喜欢修改后的造型须独立判断。

## 线稿与实体不一致时

静态线稿曾因 T 形接点处极薄三角形的舍入法向漏画真实棱。`meshDisplay` 现用面片法向构造遮挡深度面，并有回归测试。遇到可疑断线，用 `design_topology` 和主视口核对，不能直接把漏线解释为切割错误。

## 资料边界

早期社区贡献中的预设百分比统计没有附可重复统计入口，本指南不将它们作为行业合格线。交汇点方法可参考 USFG《Faceting Dictionary》《Sequencing Facets》及 GemCad 的施工示例；具体切磨角度与工艺须结合材料和原始图纸核实。心形试作的证据边界见 [琢型族谱](cut-families.md#心形探索记录)。
