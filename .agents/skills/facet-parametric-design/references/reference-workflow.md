# 参考图到真实 CUT

仅用于参考图／手绘还原，或选择参考板探索后的构造。普通参数修改、查看和导出无需读取。以用户意图、可见节点与连接为依据，保留独立参考证据；非零体积、正腰厚、平面性与全局裁切可达性均须成立。

## 1. 获取参考

说明造型目标、当前障碍与预期可观察的变化。有图直接查看所有视图；截图只解析用户原图，历史模型不提供本次节点。尽量找到原始图片并记录来源，找不到则提取参考区域并记录像素局限。

需要参考板时读 [参考板](reference-board.md)，使用可用图像能力生成效果/顶/底/侧参考板，实际查看后再解析。明确参数、预设派生和局部修改可直接构造真实方案。不要先固定生成器拓扑再用图像给它背书；需要设计词汇时再读 [面组组织](design-principles.md)，它不是配额，原图和连接不能被范本覆盖。

缺视图按 [补全](incomplete-reference.md) 明示推断后继续；图像中的高度和拓扑冲突分别记录。手绘可直线化、规整对称，但保留可见分叉。仅靠线宽不能判断的地方标成未确定。照片反射线不是已知切割棱。

## 2. 冻结独立读图记录

在求解前保存原图坐标、观察方向、唯一尺度和带语义名的节点、面环与边清单。分别覆盖台面全周、冠部各扇区、轮廓、亭部全周及底尖/底面。缺失视图单列，不给它计算还原分数。参考坐标与施工坐标分开保存；之后只能补语义面到 CUT ID 的映射。

将旋转/镜像记录成显式节点对应，不能靠最近点猜对称身份。清楚的短棱保留两个点；同一个分叉只定义一次。检查面环的凸性、共享边和层次；水平面边中点若接入另一条非共线棱，需要证明真实三维可达，不能自动把所有投影交叉当节点。

## 3. 共享节点联合构造

读 [联合构造](reference-construction.md) 与 [连接检查](topology.md)。先选择有证据的自由量，联合解完整连接链，再生成平面；默认高度不可把轮廓拉歪，也不可使不同面共面消失。

先枚举精确整数分度候选，按对称轨道统一选择，对每个候选检查全部参与点及所有保护点。相邻面不能各自取最近分度后冒充联合解。区分「整数分度上的精确可执行实体」和「与输入像素完全一致」；后者还需要独立投影误差证据。

对话设计通过正式 MCP 能力构造；明确要求的离线工程诊断可使用 [shared-planes.mjs](../scripts/shared-planes.mjs) 的共享领域原语，入口见 [实现](construction.md)。复杂链可用线性代数或独立数值求解，但不得把数值收敛当作最终实体成立，也不得用临时脚本绕过对话提交规则。

按施工前缀绑定真实顶点/棱比例点 Meet；找不到来源就保留自由参数并明确标记，不编造 fallback。相同用途、同参数且完整可生成的轨道才合组；重组后重新绑定来源。下游不是自动全局联动，修改上游后重新诊断。

## 4. 两种独立验收

工程：通过 `design_inspect`、`design_topology` 等正式能力检查完整实体的有效 CUT 面、指定连接、全局半空间可达性、共面残差、非零体积、整圈腰厚、整数分度和 Meet 来源。原石面、逻辑 CUT 与三角片分开统计。输入新底胚才读 [正式预检](custom-preform.md)。导入／导出任务核对 JSON 往返；普通参数修改不重建导入项目。明确要求离线工程诊断时，可运行：

```sh
node .agents/skills/facet-parametric-design/scripts/inspect.mjs design.json reference-topology.json
```

投影（参考图还原）：凸体 CUT 通过 `design_projection` 将独立语义图与同一保存实体比较；mesh 使用真实精确遮挡投影与拓扑检查，不将不支持的投影审计标为通过；离线诊断可用 [projection-audit.mjs](../scripts/projection-audit.mjs)。只允许平移、旋转、等比例缩放；报告每节点坐标误差、每条连接是否真实存在、缺失面/节点和全部额外可见顶点。补做可见边的双向覆盖检查，不用单一总分掩盖漏线。工具未覆盖的检查明确列为待验证，不虚构通过。`inspect.mjs` 或共点清单通过不表示输入完整、像素相似或审美通过。

浏览器：在已连接的真实工作台核实受影响的 3D／正交视图及保存结果，不重复启动服务或新建导入项目。源码涉及导入、持久化、参数编辑或 Meet 交互时，再执行对应导入、重开、编辑或解除后放弃恢复的回归；服务只绑定 127.0.0.1 临时端口。仓库测试按 AGENTS.md 的变更类型执行，纯设计数据修改不运行全仓测试。修改交互才同步受影响的产品帮助和手册；个人试作不混入内置预设或正式手册。

## 5. 交付

普通操作交付实际结果、保存状态与必要入口；参考还原另交付可编辑 JSON、同实体真实三视/3D、原图对照或叠加及逐项偏差。对话设计使用 `design_export` 等正式能力。明确要求离线诊断或独立试作页时，使用既有统一试作页，不另建产品样式：

```sh
npm run design:review -- design.json --out output/new-review --reference reference.png --views reference-views.json --notes notes.txt
```

需要裁切、来源与尺度约定时查 [参考板](reference-board.md)，离线工程入口查 [实现](construction.md)。提供可复现入口及未通过项。工程状态与设计师待验收分开；失败继续定位和修订，不删除目标、隐藏棱、压扁实体或回写参考来变绿。确有不可兼容的已知要求时，展示具体位置和经过验证的替代方案。
