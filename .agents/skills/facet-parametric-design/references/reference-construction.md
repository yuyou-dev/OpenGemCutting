# 共享节点与平面构造

这是一套手工读图配合 CAD 的原语，不是自动识图器。输入图保持独立；示例数据、求解日志和失败候选放 output/，不沉淀案例答案。

## 固定分度的平面

以单位水平法向 u=(cos θ,sin θ) 表达平面 `u·(x,y)+kz=d`。选择整数分度后，两节点不同高度时，`k=-u·(Bxy-Axy)/(Bz-Az)`，`d=u·Axy+kAz`。第三个及其余共享节点必须另检残差。相同高度的一条边只约束水平法向；仍需另一个高度来确定倾角。冠 k>0、亭 k<0。

`planeThroughNodes(index,A,B,region)` 返回规范化平面。`inspectPlane(plane,assigned,protected)` 同时检查参与点共面与保护点位于保留半空间。`patternFromPlane` 经正式领域函数生成整组 CUT；指定分度与法向不符就拒绝，不静默取整。`findPrefixTarget` 只返回真实前序顶点或棱点，内部点返回 null。

## 联合网络

每个共享节点只有一个 xyz 变量，每个面只有一个 k,d。已测高度才固定；其余高度使用明确的非退化范围。将每个面环的节点代入方程，连同镜像/旋转的显式节点对应、已知台面与边界一起求解。固定分度使等高边的 XY 方向受约束：对称面必须使用变换后的整数分度，不能逐面独立取最近齿。

先搜索读图法向附近的有限整数候选，记录尝试范围和不可行原因；如果默认高度导致明显改形，先释放该推断高度。数值求解可先低权重找近似形，再提高共面权重，但最终仍以正式内核裁切为准。保护节点、最小腰厚、面面积和体积约束不能被投影误差取代。相邻不同语义面若共面，一个会被另一面覆盖；这不是拓扑还原成功。

保存候选选择、共享节点解、CUT 结果和独立投影检查四份数据。不要复用最终顶点生成参考坐标。有限候选未找到解只能说明本次搜索范围未找到，不能宣称数学上不存在解。

## 投影审计

当前 `auditProjection` 只接受 cube CUT 的凸体；导入 mesh 仍使用其精确遮挡投影和拓扑检查，不把三角剖分当参考刻面。`fitSimilarity` 可从同名对应点求一个整体平移、旋转和统一尺度，不能消除宽高不同的变形。

`auditProjection(solid,graph,faceMap,{view,scale,center,rotation})` 输入形如：

```js
const graph = {
  nodes: { a:{pixel:[100,40]}, b:{pixel:[130,80]} },
  faces: [{id:'main',nodes:['a','b','c']}, /* 完整参考面环 */],
  edges: [['a','b'], /* 完整参考连接 */]
};
```

`faceMap` 只将事先语义映射到正式 CUT ID。轮廓节点需要其腰面身份来区别同一条冠棱的两个端点。不得靠离参考最近的实体点掩盖错误身份。返回逐点误差、真实直接连接和额外可见顶点；若有合法共线细分，须另行按同一支撑面检查边链并记录，不扩大容差焊接。额外点列表包含合法的腰部轮廓细分，应逐项归类。

反向从实体检查全部可见棱，解释多余线；侧视透叠导致不确定的连接单列。叠加线必须从正式正交投影生成，不能用参考线当模型。统一缩放保留每张输入的原始宽高比；多视图原始像素倍率不同，分别记录倍率和用于注册的轴。
