# 本项目构建入口与实测陷阱

仅供明确要求的离线工程诊断或相关源码维护；普通对话设计使用正式 MCP 能力，不要求读取本页或运行领域脚本。离线诊断从仓库根目录运行。生成器使用 `src/domain/faceting.js` 的 `resolveFacetPattern`、`createFacetingDocument`、`exportFacetingJSON` 和 `importFacetingJSON`；工序与来源诊断使用 `buildConstructionStages`；目标枚举与求解使用 `meetJump.js`；实际正交投影使用 `technicalPreviewSvg`。先查当前导出与签名，勿猜 API。数学脚本不依赖 React／DOM。

- `repeat` 是旋转重复。`mirror` 是相对主面偏移的反射轴族，不是绝对轴角。对 N 齿分度，X 反射对应轴 index N/4 模 N/2，单组镜像偏移 `(N/4-baseIndex) mod N/2`；96 齿时即 24 模 48。用 `generateFacetIndices` 和该层 `indexTeeth` 验证结果，不靠口诀。
- 同角同深不是合组的充分条件：还须同设计用途、完整可生成的索引集合、兼容来源与工序顺序。若多种表达等价，优先最大真实旋转次数及更简单的镜像表达。
- `resolveFacetPattern` 用一组公共参数生成成员；保持该组齿数、小数索引、全精度角度／深度、主成员和元数据。目标设备的整齿可加工性从真实法线另行检测，不改变保存参数。存相同 patternId 的独立错误平面不能冒充联动。
- 两端点 sourceFaceIds 的交集才能判断一条棱由哪些面支撑；边来源的并集可能混入端点附近的面。错误识别曾导致选到亭尖而非腰边。
- 环上等距候选不能任取首个顶点，需按对称几何目标投影到真实棱，否则数值上会丢失旋转对称。
- 双 Meet 绑定当前施工前缀的真实点或棱比例点。重组或变换要重新枚举、绑定与诊断，不能只替换来源 id 或 fallbackWorldPoint。
- 不把“最大切除量”当作拟合目标。参考要求保留腰带时检查实际腰厚，并按参考拟合分叉与外围落点；允许覆盖不等于满足具体设计意图。合法闭合实体也可能因缺少参考要求的腰面而拟合失败。
- 高度按 Z 缩放可保持顶视线网，但改变真实角度。相应更新显式平面、参数与来源；超过毛坯包络时可整颗等比例缩小，报告比例保持而非物理尺寸不变。
- 平底是亭部水平 CUT：法线朝 -Z、行业角 0°、repeat 1，不标记成固定冠部台面。截切位置和相邻主面共同决定底面形状，必须检查实际底面边数，不能给一个八边形贴“四边形”标签。

稳定性来自分层检查，不来自宣称“一次成功”：输入意图 → 拓扑 → 对称轨道 → 平面求解 → 完整工序诊断 → 归一化三视对照 → 浏览器参数调整及保存。
