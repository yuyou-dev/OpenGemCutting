# 面组组织与设计丰富度

## 默认设计取向（本技能的选择，不是行业标准）

没有少面、极简、玫瑰式或明确原图约束时，先以**约50–80个非腰有效面**考虑完整设计，并参考同类实体；较复杂枕形可以更高。冠、亭分别考虑约24–40个斜面及其用途，二者不必等数。数值是构思尺度，未求解时标“目标”，不能靠拆分共面三角形、添加无效CUT或密集腰面凑数。

- 明亮式方向：考虑台面、星面、冠主面、上腰面，以及亭主面、下腰面、近腰分叉和尖底／平底。每组要说明如何连接，不要求所有类型都具有同一种拓扑。
- 阶梯式方向：用阶梯宽度、转角与冠亭比例设计大面节奏；保留选定的冠亭排数，不因“阶梯”就退成一两圈。上表三排方案是参考，不是强制模板。
- 混合式方向：冠部可以较安静，亭部采用更丰富的放射、分叉或交错面网。不得把冠部样式机械镜像到亭部。
- 凹轮廓：先给每个叶瓣／常规扇区完整面组，再设计凹口局部过渡。局部大面例外不免除其他扇区的星面、腰面和亭部分叉；全局CUT可达性另检。
- 非腰面明显偏少（如不足40）或某一侧只剩少数大面时，主动复查设计意图、同类例子和缺失面组。允许有理由的少面方案，不机械补面，也不例行要求用户批准面数。

先写一份简短面组计划：`部位 / 面组用途 / 重复与镜像 / 目标成员数 / 必须连接到哪里 / 允许改变什么`。最终逐组核对有效面及连接，不能只核对总数。组数多不证明丰富，数值有效但几乎共面、极窄或难以辨认的面也要目视评估；不设置通用最小角差或面宽来替代设计判断。

## 防止修图时整体降级

每次修订先记录变更范围：本次要解决什么、冠部保持什么、亭部保持什么、底胚保持什么。把原版和修订版并排保留，并比较冠亭各组的成员、连接、排数／分叉、底部类型及轮廓。

修冠部比例、标签、凹口饰线或画板排版，不应顺带删除亭部层次。优先局部重绘、保留未修改视图；若图像模型把亭部简化，不能接受这张图来降低施工目标。侧视漏画一圈而底视仍有该圈，属于待修图稿，不可用后来的实体补图倒称原稿一致。

对原创未被用户限定的方案可自行解决局部绘图错误，但应保留面组计划所表达的丰富度。确实需要删减面组或改变已认可部位时，明确差异与理由；涉及改变用户要求则展示可执行替代方案再询问。不能把本轮主动选了简洁34面归因于“凹型只能少面”。
