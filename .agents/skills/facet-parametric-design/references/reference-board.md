# 无图设计与参考板范本

适用于没有参考图的新琢型设计。默认完成“文字意图 → 设计参考板 → 连接清单 → 参数化切割 → 同实体三视对照”，不要停在效果图，也不要先做完实体再把实体截图冒充事先设计的参考。

## 固定呈现形式

以下布局定义通用参考板。若用户提供认可的范本，先查看再复用其构图和信息层级，不复用具体琢型。个人参考图留在用户工作区，不作为公开 skill 的运行依赖。

- 横向单张设计板，默认约 3:2；浅色干净背景、克制的细线与留白。标题给出本次设计名和琢型类别。
- 左侧约四成：一颗完整宝石的立体效果预览，清楚呈现轮廓和冠部层次；色彩服务设计表达，不用镶嵌或装饰遮挡琢型。
- 右上：并排的 **TOP / 顶视** 与 **BOTTOM / 底视**。右下：横向 **SIDE / 侧视**。三者均为真实正交含义的清晰线框，无透视、折射重影、填色纹理或遮挡关键棱的标注。
- 三视图统一方向和尺度基准：明确腰宽及长宽比，保留各自比例；顶／底视标明同一头尾方向。侧视显示冠高、腰厚、亭深以及台面与底尖／平底。必要时明确侧视沿哪个轴观察。
- 标注至少包含视图名、轮廓长宽比、台面相对宽度、冠高／腰宽、腰厚／腰宽、亭深／腰宽、底尖或底面类型。异形台面或底面补长宽／位置；设计依赖的阶梯或分叉位置补必要比例。标注不穿过线网。

比例统一以腰宽为基准，例如“腰宽 W = 100%；冠高 / W = …”。用户未指定实际尺寸时使用无单位比例，不能自行冒充毫米。面数、齿位、行业角只有已求解确认后才作为施工数据；出图阶段的设想须标成设计目标，不伪装成已验证参数。

## 先定义本次造型，再出图

先读取 [面组组织与设计丰富度](design-principles.md)，选择明亮式、阶梯式或混合式的设计方向，分别写冠、亭面组计划。不要沿用范本的少量环面，也不要把约50–80非腰面这个构思范围标成已完成面数。

用一句话概括设计意图。结合用户要求确定轮廓、台面、冠亭结构、底部收束、各层旋转／镜像规律和比例目标；缺失信息自行作合理选择并记录。考虑96齿整数分度、平面刻面和正腰厚的可表达性，但不要因此把不同设计都改成八角阶梯。

将应共享的节点、保留的短棱、星面／主面／腰面交接、亭部分叉或底面连接写入生成要求。水滴、心形、枕形、阶梯、混合式等分别设计；三视图中的扇区数量与连接对象必须对应。不能只写“复杂、漂亮、闪亮”让出图模型自由补线。

使用当前可用的图像生成能力；用户指定工具时遵从。未指定且 `image_gen` 可用时用它生成参考板。把用户提供的图作为版式参考时明确“只参考排版，不继承琢型”，同时写明新轮廓与连接要求。图像工具的生成、引用与等待方式遵守其工具契约。输出放本次独立的 `output/` 或 `tmp/` 目录；若图像能力不可用，如实说明阻断，不能声称已经生成参考板。

可复用的提示词骨架（将花括号替换为本次具体设计，不照抄范本参数）：

> 生成一张专业宝石琢型设计参考板，横向3:2，浅色纸面，精细且高对比的技术线条，充分留白。标题为{设计名／琢型类别}。严格采用以下信息布局：左侧约40%展示一颗完整的{本次轮廓、颜色、冠部结构}宝石立体效果预览；右上并排顶视TOP和底视BOTTOM，右下为侧视SIDE。右侧必须是清楚可逐根辨认的正交线框三视图，不含折射重影，不用效果渲染代替线框。设计理念为{大面节奏／星面与主面／分叉亭部等具体意图}。具体结构为{台面、冠部各层、腰部、亭部各层、底尖或底面}；面组计划为{冠部各组用途与目标成员数；亭部各组用途与目标成员数}，非腰面约{本次选择的范围或少面理由}仅为设计目标。不能用反射线、共面内缝或密集腰面充当面组。各层对称为{旋转次数、镜像关系、主方向}；必须连接的节点与棱为{完整扇区及共享节点关系}，明确保留的短棱为{位置或无}。三视图与左侧预览表现同一个琢型，层数和连接一致。亭部必须完整画出{近腰分叉／全部阶梯／底部连接}，不能只画少数大面。{凹轮廓时：说明自定义预成型边界与保留凹壁；后续CUT是全局平面，不能只切一片叶瓣。}统一腰宽W，标注{长宽比、台面宽/W、冠高/W、腰厚/W、亭深/W、底部及其他必要比例}，标注置于轮廓外。比例是本次设计目标；不生成未经求解的角度或齿位表。不继承范本的八角轮廓、阶梯层数或数值。

## 出图检查与矛盾处理

重绘提示词还须列出“只修改什么／冠部保留什么／亭部保留什么／底胚保留什么”；参考图的局部错误不能变成删减亭部面组的理由。原版保留，复查未要求改变的区域。

生成后实际查看整张图片，确认左侧预览、三幅线框和标注齐全，并逐视核对轮廓、台面、每个扇区、底部类型与对称。数一遍面环及分叉；效果图里的折射线不计为切割棱。量取图中比例，检查其与标注及文字设计目标的关系。

对缺视图、线网不清、冠亭不同轮廓、错误层数、错接、底尖和平底冲突等结构问题，先重绘／修订参考板再建模。本轮自己设计的未限定细节可直接修订，不必加审批步骤；涉及改变用户已明确要求或已认可部位时，按主技能的异常处理说明具体冲突与可执行替代方案。

小幅绘图比例误差可以按本次明确的文字目标建模，并在试作说明中标明；没有明确目标时从一致的视图量取，不能无声选取自己偏好的数字。清楚的分叉、共享角和短棱不属于可忽略的比例误差。仍然矛盾的视图不能用“工程检查通过”证明已还原。

生成参考板可能出现视图与标注比例不同、底部多余短尾等矛盾；**呈现形式合格不等于工程图无误差**。新任务应检查并修订这些矛盾。也不要继承“所有图都以标注优先”的规则：先看本次用户意图与一致的设计目标，再修订或解释差异。

## 接入真实切割与交付

参考板核对后，回到主技能的“从图到约束”和“连接关系优先”：在求最终实体前建立独立、覆盖完整的参考连接清单，再选择参数并绑定真实施工前缀Meet。可以先做可行性推导，不能从成功实体反推验收目标或删除失败节点。

继续完成工程检查、真实工作台导入、参数组联动、Meet恢复、放弃恢复和项目保存。统一试作页使用本次参考板与同一保存JSON；三视裁切从本次实际图片量取，不能照搬其他参考板坐标。分别说明已实现的造型、生成图误差、建模推断和仍待用户判断的审美取舍。

用户后续只要求修订已认可设计时，保留该版本的参考和参数化文档；除非要求重新设计，不重新随机出一张参考图替换已认可方向。
