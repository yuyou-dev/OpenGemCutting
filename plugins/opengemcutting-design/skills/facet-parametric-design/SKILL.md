# Facet 96 对话入口

仅用于打开、查看或操作当前项目配置的 Facet 96 工作台，不用于源码开发或规则问答。同类入口只选一个；已加载本地设计 Skill 时复用它。

读取 `facet://guide`，通过 `workbench_open` 返回的完整链接在内置浏览器连接，经 `workbench_sessions` 与 `design_read` 核实项目后继续用户请求。复用同版本资源与已验证连接；切换项目、断线或版本变化再核实，目标仍不明才询问。HTTP 成功不代表连接成功。

查看／导出执行对应工具；创建或修改时读取 `facet://skill`，由其路由具体流程与验收。已授权的普通有效修改检查后提交保存；使用最新 revision 并保留手动草稿保护，整体消面只提示影响，可直接提交和撤销。不用直接写 JSON 或临时修改源码绕过正式能力。

工具缺失先诊断连接、加载与安装状态；仅在任务授权包含安装配置时执行所选项目 INSTALL.md。不要在插件缓存中建立项目。无法连接或保存时报告具体阻碍，不假报完成。此入口不负责社区维护或 GitHub 写操作。
