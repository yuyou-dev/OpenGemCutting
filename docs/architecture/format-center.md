# 格式中心

格式中心让设计师打开 GemCAD、Gem Cut Studio 的设计，或把当前设计交给这些软件，并在转换前看清哪些信息保留、简化、丢失或不能转换。实现：领域层 [`src/domain/formats/`](../../src/domain/formats) 与 [gemcadAsc.js](../../src/domain/gemcadAsc.js)，应用层 [formatCenter.js](../../src/application/formatCenter.js)，页面 [FormatCenterPage.jsx](../../src/components/FormatCenterPage.jsx)。ASC 文本规则见 [GemCad ASC](gemcad-asc.md)，页面状态边界见 [状态契约](state-contract.md#项目与页面)，版式见 [视觉规范](design-system.md#格式中心)。

## 入口与流程

- 入口唯一：主页“格式中心”；编辑页文件菜单“从 GemCAD / Gem Cut Studio 导入…”（进入并打开文件选择）与“导出到其他软件…”（以当前项目为来源）。JSON 导入导出与 PDF 报告仍在文件菜单。
- 来源：当前项目（已提交版本，未提交切割预览不参与）或一个文件（`.asc`、`.gem`、`.gcs`、本软件 `.json`）。按内容识别格式，扩展名不一致只作说明。
- 去向：文件来源可“在工作台打开”（新建独立项目，经 App 的未保存预览确认）、另存为 `.asc`、`.gcs` 或本软件 `.json`；当前项目可导出 `.asc`、`.gcs`。GEM 只读。同格式不作为去向。
- 读取和转换都不修改原文件或当前项目；导出只下载新文件。

## 中立平面模型（PlaneDesign）

所有外部格式先读入同一模型，再写出。坐标为本项目机器坐标：Z 向上，分度 `index` 的方位为 `index × 360 / gear`，自 +X 逆时针。层角使用 GemCAD 带符号约定：冠部正、亭部负、腰部 ±90、台面 0，底尖为 0° 且距离为负；距离从旋转轴上的一点量起。每层含 `entries`（分度、源标记、刻面名、表面、GCS 原值），可带 `hidden`、`table`、`name`、`instructions`；文件级保留标题、脚注、折射率与各格式附加信息（`extras.asc / gcs`）。

- 工作台文档 → 模型：只取完整已提交实体的最终有效面（与 ASC 相同），按保存的源顺序，再按亭部、腰部、冠部、台面排序；凹切、导入晶体和空实体阻断；所有省略均以诊断报告。
- 模型 → 工作台文档：要求唯一 0° 台面（成为固定 T1）；逐面保留层名、说明、源顺序（历史命名的 `metadata.asc` 交换簿记）、磨砂 `surfaceFinish` 与 GCS 原值 `metadata.gcs`；隐藏层存于文档 `metadata.gcs.hiddenTiers`，再导出 GCS 时写回。
- 无台面或多台面的设计不能进入工作台，但可直接在 ASC、GCS 之间转换。

### 进入工作台的统一比例

切割深度必须非负，且整颗宝石必须在毛坯内：先按“各平面距离不超过旋转包络支撑”求比例，再以闭合实体的最大坐标收缩到毛坯内（留百万分之一余量，使恰好贴在毛坯面上的平面仍是真实切面）。只做统一缩放，角度、分度、L/W 与高度比例不变。此前只满足深度非负，多边腰棱角等会被毛坯削出细条（例如标准圆钻的 16 面腰）。内置预设 JSON 未重新生成，不受影响；重新生成预设时按此规则。

## Gem Cut Studio（.gcs）

依据 Gem Cut Studio 1.1 手册文件格式一节与 1.1 桌面实际存档（样本见 [fixtures](../../src/domain/formats/fixtures/README.md)）。

| 项目 | 规则 |
| --- | --- |
| 根与版本 | `<GemCutStudio version>`；大于 1000 警告按 1.1 读取；未识别字段计数提示，不读取 |
| `index` | `gear` 为 1–360 整数；`base`、`symmetry`、`mirror` 是界面状态，原样保留写回，不推断设计对称 |
| `tier angle` | 法线极角：0 台面、90 腰部、大于 90 亭部、180 平底尖；以刻面法线为准，层角只作核对 |
| `depth` | 平面到文件原点的距离；缺失时由顶点推算。顶点只是缓存（1.1 存档自身有约 1e-5 误差），与平面不一致时按平面重算 |
| 坐标 | GCS 方位 + 90° = 本项目方位（绕 Z 旋转）。原点不在宝石内部时只沿旋转轴移动参考点；轴本身在宝石外则拒绝 |
| `index_angle` | 冠部 = 本项目方位；亭部与腰部 = 360° − 本项目方位（转接后分度反向）。与法线不一致时以法线为准并提示核对 |
| 磨砂 | `frosting > 0`（1.1 存档写 `0.5`）→ 本项目磨砂 `alpha 0.25`（实验室默认），原值存 `metadata.gcs.frosting` 并原样写回；新磨砂面写 `0.5`；α 不写入 GCS |
| `visible="false"` | 原软件中暂不切的层：不切入形状，另存 GCS 时保留；ASC 不保存 |
| `guide` | 原样保留写回，不推断用途 |
| `render`、`info` | 保留写回；折射率双向同步。标题只有 `title`、`header2`，脚注只有 `footer1/2` |

写出：以旋转轴为原点、垂直居中、半宽或半高为 1（与实际存档一致），每面写法线、分度角、层深度和由本项目求得的顶点，数字保留 15 位有效数字。不闭合的设计阻断。带旋向（无镜像对称）的方向已实机确认：2026-09-25 用户在 Gem Cut Studio 1.1 中并排打开冠部相对亭部偏转 2 齿的“风车”圆钻，格式中心转换的 GCS 与 Gem Cut Studio 自带的 ASC 导入列出相同的冠部分度（C1 02-14-26…86、C2 09-21-33…93，镜像会变为 94-82-70… 与 87-75-63…），渲染一致；该设计作为回归测试保留。

## GemCAD 存档（.gem，只读）

没有公开规范。结构参照 Mike Parker 的 MIT 读取器 [gemcad-file-reader](https://github.com/mbparker/gemcad-file-reader)，并用同名 `.gem`／`.asc` 样本逐层核对：每面为平面向量 `p`（`p·x = 1`，距离 `1/|p|`）、层号、“名称\t说明”、多边形顶点；尾部为对称、镜像、带符号齿数、折射率、齿位与长度前缀文字（标题、空白分隔、脚注）。GemCAD 坐标与本项目交换 X、Y，与 ASC 保持相同分度数字。逐项读取都有越界、非有限数字、层数、顶点数与 20 MB 上限；找不到尾部或含 `preform` 段时拒绝，不猜测。

## 损失说明

- [capabilities.js](../../src/domain/formats/capabilities.js) 是唯一登记：每项设计信息的设计师名称、用途和四种格式的保存能力（保留／简化／不保存／不能转换），以及对应的写出诊断代码。页面对照表读取该登记。
- 单个设计的报告由实际写出时的诊断决定：只列这个设计里存在的信息；写出器报告的才算简化或丢失，其余为保留。测试保证登记的每个损失代码都有写出器真实产生。
- 结果分四档：完整保留、会简化 N 项、会丢失 N 项、不能转换。无损时直接导出；有损时按钮为“了解差异，导出 …”，一次点击即确认，不另设勾选或弹窗。需要在对方软件核对的事项（如旧版 GemCAD 的文字编码）单独列出。
- ASC 与 GCS 导出后立即用对应读取器读回，按包围盒中心与半尺寸归一比较全部有效平面；不一致则阻断并提示保存 JSON 反馈，不提供文件。
- 编辑器会话、界面对称设置等非设计数据的提示不进入设计师报告，只在技术细节中保留完整诊断。

## 安全与边界

文件只作为数据读取：不执行、不联网、不展开外部实体。XML 仅支持 Gem Cut Studio 所需子集，拒绝 DTD、自定义实体、非法字符引用、重复属性、控制字符，并限制节点 250000、深度 64、每节点属性 64；属性表无原型。数字只接受有限十进制。文本先按 BOM 或 XML 声明解码，否则 UTF-8，不合法时按旧版 Windows 西文编码读取并提示核对。文件上限 20 MB、层与面各 4096、顶点 150000；进入工作台的设计另经导入预算与几何校验。

## 可选 MCP

`design_export` 的 `format: "gcs"` 与页面使用同一应用层，返回文本、诊断、保留／简化／丢失报告与读回核对结果；`asc` 返回形状不变。

## 测试与样本

| 范围 | 覆盖 |
| --- | --- |
| XML 安全 | DTD／外部实体、未定义与非法字符引用、重复属性、嵌套与属性上限、原型名、转义往返 |
| GCS | 1.1 实际存档与预设 100058 的方向一致、改角存档、磨砂原值往返、隐藏层、冠／亭／腰分度标注、带旋向设计的冠部分度、标注不一致、不闭合与非法数字 |
| GEM | 合成编码器：与 ASC 同形、名称与说明、标题脚注、反向齿盘与齿位、preform／截断／非有限数字拒绝 |
| 平面模型 | 进入毛坯的统一比例、贴毛坯面的平面、陡亭部闭合判断、形状比较、登记与写出器代码一致 |
| 应用层 | 内容识别、去向列表、各档结果、无台面直接转换、凹切阻断、JSON 来源、工作台文档往返 GCS |

`.gem` 第三方设计不入库；开发期另用 GemCAD 发布的标准圆钻与 Cube Illusion Triangle 的 `.gem`／`.asc` 对照（仅本机 `tmp/`）。格式内核源自用户自有、按 MIT 发布的 Facet Format Bridge 探索版 0.1.0-rc.1，按现行文档模型、表面模型与 ASC 模块重写，不含探索版的项目模型或切割逻辑改动。
