## 工程范围

发布前统一执行 `npm run check:mcp`：文档链接、安装生命周期、领域与 skill、Companion、构建、Sites、MCP 连接及版本一致性检查。根目录与 mcp 的依赖分别审计；Pages 子路径单独构建并在浏览器核实。2026-09-11 的 1.0.0 本地检查全部通过，共 320 项；根目录与 MCP 依赖审计均为 0 已知漏洞，公开敏感信息扫描通过。30 页手册的全页版式、可搜索中文和 1.0.0 版本已经核对，两套设计插件通过官方校验。

已实际验证的对话流程包括页面与项目匹配、圆形起点、冠部比例预览/提交、撤销/重做、保存及 JSON 重开。普通静态页面能够在没有 MCP 的情况下新建和编辑。
