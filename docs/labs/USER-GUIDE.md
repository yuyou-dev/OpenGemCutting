# 实验室使用指南

实验室主页只把图案实验室作为新实验入口；冠亭预设实验室已并入编辑器，主页上的说明卡指向编辑页操作栏「刀具库」中的“圈层组合”，结果直接写入当前设计和撤销历史。已有冠亭实验稿仍在“最近实验”中继续。先选择实验室，再新建实验或带入当前已保存设计；切换选择不会修改项目。没有来源时仍可新建，有未保存切割时先完成当前操作。

新建图案默认保持抛光，不自动添加磨砂细边。需要细边时，在右侧「表面控制台 → 磨砂细边」设定宽度，再开启「冠部应用」或「亭部应用」。继续旧实验会保留其原有设置。拖动编辑时，计算提示显示在平面画布右上角，画布不会因此改变高度。

## 冠亭预设实验室

当前固定交付的版本与内容指纹由 [锁文件](../../src/application/presetModuleLock.json) 记录，工程说明见 [实验室现状](README.md)。模块以 MIT 交付，依赖许可与字体声明随固定包提供。实验室内部界面目前为中文。主页不再新建或带入冠亭实验，以下流程与边界适用于从“最近实验”继续的已有实验稿。

复现创意流程：从“最近实验”继续一份冠亭实验稿 → 选择阶梯式冠部 → 圈层第 2 圈错位 +1 齿 → 比较变体 → 载入或撤销 → 应用冠部并搭配亭部 → 应用 → 保存退出 → 继续实验 → 检查并带回。比较使用同视角和同比例的真实几何，设计师自行判断腰口、圈层与两半比例。结果不代表光学或可加工性认证。

创意设计支持台面开合、星面舒展、冠部起伏、亭部深浅；圆形阶梯与错层环式支持逐圈层宽和整齿错位。圈层配方保存为 recipe v2，旧配方仍可读取。保存退出会保留尚未应用的参数；检查并带回要求先处理待应用修改，结果保存为独立项目，来源不被覆盖。

接受 cube 和有界凸 mesh 来源，保留原 stock、切深参考、已保存切割、表面、Meet 信息及已知毫米尺度。非凸 mesh、非空凹切、未知必需扩展或未来格式明确拒绝。凸 mesh 可输出 JSON 与加工 PDF；格式中心当前不提供 mesh 的 ASC／GCS 转换。未知尺度不会被猜成毫米。

## 图案实验室与草稿

图案实验室保持既有 cube 来源边界；冠亭可接受的 mesh 不表示图案实验室也能接受。最近实验稿注明所属实验室，可继续创作。兼容的旧冠亭实验稿升级保存前会备份，未来版本拒绝且保留原文件；旧稿备份不能通过改版本号强制降级。

两个模块均随产品固定交付，无需相邻实验室服务。模块版本升级经过内容校验和宿主测试；卸载或退出释放视图资源，保存失败保留现场。MCP 未新增实验室内部设计工具，带回工作台后继续使用既有 MCP 能力。

## 多窗口保存与磨砂面识别（2.0.0）

同时在两个窗口修改同一实验时，先保存的一方正常保留，另一方会看到冲突提示，当前改动仍在内存中。请先点击“下载恢复文件”，在实验室总览选择“从恢复文件另存”；恢复后是独立实验稿，不覆盖另一窗口保存的方案。

检查并带回编辑后，磨砂面以冷灰色显示，主视图有对应图例；选中或编辑时仍以操作高亮优先。切割助手走到磨砂面时提示“磨砂切割 · 无需抛光”。颜色只是加工属性提示，不改变切割参数。
