# 实验室模块

当前版本以固定 MIT 交付包随产品构建，无需单独启动实验室服务。

| 模块 | 版本 | 公共契约 |
| --- | --- | --- |
| 图案实验室 | 0.6.0-rc.3.main.9492ad270b21 | 1.3.0 |
| 冠亭预设模块 | 0.5.0-rc.10 | 1.3.0 |

图案实验默认不开磨砂细边；旧稿保留原有表面设置。冠亭构造从编辑器刀具库的“圈层组合”使用，已有实验稿仍可从最近实验继续。使用方法见 [使用指南](USER-GUIDE.md)，数据交换见 [公共契约](CONTRACT.md)，文档边界见 [状态契约](../architecture/state-contract.md)。

`src/application/labsModuleLock.json` 与 `presetModuleLock.json` 锁定模块目录及指纹；许可和校验清单随对应 vendor 目录提供。公开版本仅携带当前锁定包，旧交付保留在发行历史；依赖旧包的升级测试会明确注明跳过。不要手动改动固定包文件或版本号。
