## 设计师验收入口

- 导入 `docs/manual/examples/01-round-start.json`，检查 49 个有效面与真实顶/侧视图。
- 进入切割助手，在第 38/49 刀观察下一刀的分度、角度和深度；播放、暂停、逐组、跳转到末刀，再退出核对原设计。
- 手动旋转后跟随应暂停；重新开启后平滑回到当前面，比较舒缓和快速转场。
- 运行 README 的试作命令，切换四个方向，下载 JSON 后在新项目中导入。
- 阅读 README、PDF 和插件安装说明，确认能找到起点及留存设计的入口。

工程通过不代填设计师的视觉、阅读距离、切磨节奏与操作舒适度评价。实体切磨和光学收益不在软件回归中验证。插件远程安装需在代码推送后再次验证；本地校验不能证明远程 main 已包含候选包。
